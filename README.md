# Python-Mega-Project-Personal-AI-Voice-Assistant-System
This Voice Assistant System is an AI-powered personal assistant inspired by JARVIS, featuring two modules: a CLI-based assistant that executes voice commands like opening apps, playing music, and searching Wikipedia, and a web-based multilingual assistant using Google Gemini with a Streamlit interface, supporting natural language queries with text
